# Vouch logo concept

Asset: [vouch-logo-v1.png](vouch-logo-v1.png)

Original logo exploration inspired by the broad simplicity of the startup references; no affiliation or investment claim is implied. Transparent raster logo with a receipt-inspired V/checkmark and Vouch wordmark.

## Project usage

`app/components/BrandLogo.tsx` uses this original PNG on the landing page and in both console sidebars. CSS removes transparent margins at display time and shows the symbol alone when navigation is collapsed. The original asset is preserved unchanged.
